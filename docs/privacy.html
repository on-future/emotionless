emotionless 개인정보처리방침

시행일: 2026년 11월 12일

emotionless(이하 "확장 프로그램")는 웹 페이지의 댓글에 감정 이모티콘을 표시하고 감정 표현을 순화해 보여 주는 Chrome 확장 프로그램입니다.

1. 기본 동작: 수집하는 정보 없음

확장 프로그램은 기본 상태에서 어떤 정보도 기기 밖으로 보내지 않습니다.

  • 방문한 페이지의 주소, 댓글 내용, 사용 기록을 전송하지 않습니다.
  • 분석 도구, 광고, 추적 코드를 포함하지 않습니다.

2. 기기 안에서 처리하는 정보

확장 프로그램은 다음 정보를 사용자의 기기 안에서만 처리합니다.

  • 페이지의 댓글 글: 감정을 분류하고 순화된 글을 만들기 위해 읽습니다. 분류는 확장 프로그램에 포함된 모델이 기기 안에서 수행하며, 처리한 글은 저장하지 않습니다.
  • 설정 값: 사용 여부, 걸러 보는 정도, 사용자가 직접 지정한 사이트별 댓글 위치 등을 브라우저의 로컬 저장소(chrome.storage.local)에 저장합니다.
  • 사용자가 고친 내용: 얼굴을 눌러 고친 감정과 드래그해 지정한 표현을 로컬 저장소에 저장해 이후 판정에 반영합니다.

이 값들은 확장 프로그램을 삭제하면 함께 삭제됩니다.

3. 선택 기능: 고친 내용 보내기

사용자가 "고친 내용을 개선에 보내기"에 동의한 경우에 한해, 사용자가 판정을 고칠 때마다 다음 정보를 개발자의 서버로 보냅니다. 동의하지 않으면 아무것도 보내지 않으며, 설정에서 언제든 끌 수 있습니다.

  • 사용자가 고친 댓글의 글 (최대 300자)
  • 원래 판정과 사용자가 고른 감정, 또는 사용자가 지정한 표현
  • 그 댓글에 대해 모델이 낸 점수
  • 무작위로 만든 설치 식별자와 확장 프로그램 버전

보내지 않는 것: 페이지 주소, 댓글 작성자, 사용자가 고치지 않은 댓글, 계정 정보.

이 정보는 감정 판정과 표현 순화의 정확도를 높이는 데에만 쓰며, 제3자에게 판매하거나 제공하지 않습니다. 여러 사용자가 같은 의견을 낸 내용은 검토를 거쳐 모든 사용자의 확장 프로그램에 내려보내 판정에 반영합니다. 서버의 접속 기록에는 IP 주소가 남을 수 있으나, 보내 온 내용과 연결해 저장하지 않습니다. 보낸 내용의 삭제를 원하면 아래 문의처로 요청할 수 있습니다.

4. 권한

  • 모든 사이트의 페이지 읽기 및 변경: 댓글이 있는 페이지에서 댓글을 찾아 화면 표시를 바꾸기 위해 필요합니다.
  • 저장소(storage): 위 설정 값을 기기에 저장하기 위해 필요합니다.
  • 오프스크린(offscreen): 감정 분류 모델을 기기 안에서 실행하기 위해 필요합니다.
  • 활성 탭(activeTab): 확장 아이콘을 눌렀을 때 현재 사이트의 설정을 보여 주기 위해 필요합니다.

5. 방침의 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다.
