emotionless 개인정보처리방침

시행일: 2026년 11월 13일

emotionless(이하 "확장 프로그램")는 웹 페이지의 댓글에 감정 이모티콘을 표시하고 감정 표현을 순화해 보여 주는 Chrome 확장 프로그램입니다.

1. 댓글 처리: 기기 밖으로 나가지 않음

댓글을 읽고 감정을 분류하고 표현을 순화하는 일은 모두 사용자의 기기 안에서 이루어집니다.

  • 방문한 페이지의 주소, 읽은 댓글, 사용 기록을 전송하지 않습니다.
  • 분석 도구, 광고, 추적 코드를 포함하지 않습니다.

기기 밖으로 나가는 정보는 3번에서 설명하는, 사용자가 동의한 뒤 판정을 직접 고쳤을 때의 그 내용뿐입니다.

2. 기기 안에서 처리하는 정보

확장 프로그램은 다음 정보를 사용자의 기기 안에서만 처리합니다.

  • 페이지의 댓글 글: 감정을 분류하고 순화된 글을 만들기 위해 읽습니다. 분류는 확장 프로그램 안의 모델이 기기 안에서 수행하며, 처리한 글은 저장하지 않습니다.
  • 설정 값: 사용 여부, 걸러 보는 정도, 사용자가 직접 지정한 사이트별 댓글 위치 등을 브라우저의 로컬 저장소(chrome.storage.local)에 저장합니다.
  • 사용자가 고친 내용: 얼굴을 눌러 고친 감정과, 드래그해 지우거나 바꾸거나 그대로 두라고 지정한 표현을 로컬 저장소에 저장해 이후 판정에 반영합니다.

이 값들은 확장 프로그램을 삭제하면 함께 삭제됩니다.

3. 고친 내용 보내기 (동의한 경우에만)

사용자가 처음으로 판정을 고치면, 고친 내용을 개선에 보낼지 묻습니다. 사용자가 "보내기"를 고른 뒤에만 보내며, "보내지 않기"를 고르거나 답하지 않고 닫으면 아무것도 보내지 않습니다. 설정의 "고친 내용을 개선에 보내기"에서 언제든 바꿀 수 있습니다.

동의한 경우, 사용자가 고친 댓글에 대해서만 다음 정보를 개발자의 서버로 보냅니다.

  • 사용자가 고친 댓글의 글 (최대 300자)
  • 원래 판정과 사용자가 고른 감정, 또는 사용자가 지정한 표현과 바꾼 말
  • 그 댓글에 대해 모델이 낸 점수
  • 무작위로 만든 설치 식별자와 확장 프로그램 버전

보내지 않는 것: 페이지 주소, 댓글 작성자, 사용자가 고치지 않은 댓글, 계정 정보, 방문 기록.

이 정보는 감정 판정과 표현 순화의 정확도를 높이는 데에만 씁니다. 구체적으로, 여러 사용자가 같은 의견을 낸 내용을 모아 판정 모델을 다시 학습하고, 모든 사용자의 확장 프로그램에 반영합니다. 학습과 품질 확인 과정에서 운영자가 보낸 내용을 볼 수 있으며, 이 사실은 보내기 전 안내에서 알립니다. 제3자에게 판매하거나 제공하지 않습니다. 서버의 접속 기록에는 IP 주소가 남을 수 있으나, 보내 온 내용과 연결해 저장하지 않습니다. 보낸 내용의 삭제를 원하면 아래 문의처로 요청할 수 있습니다.

4. 개선된 모델 받기

확장 프로그램은 하루 한 번 개발자의 서버에 개선된 판정 모델이 있는지 확인하고, 있으면 받아서 기기 안에서 씁니다. 이때 서버로 보내는 정보는 없습니다(일반적인 웹 요청처럼 IP 주소만 전달됩니다).

  • 받는 것은 모델의 가중치와 계산 구조(ONNX 파일)와 그 설명뿐이며, 실행 코드(JavaScript, WebAssembly)는 받지 않습니다. 모델은 확장 프로그램에 포함된 실행기로만 돌립니다.
  • 개발자의 서명이 확인된 모델만 쓰고, 파일의 해시·크기·형식이 맞지 않거나 열 수 없으면 버리고 확장 프로그램에 포함된 기본 모델을 씁니다.

5. 권한

  • 모든 사이트의 페이지 읽기 및 변경: 댓글이 있는 페이지에서 댓글을 찾아 화면 표시를 바꾸기 위해 필요합니다.
  • 저장소(storage): 위 설정 값을 기기에 저장하기 위해 필요합니다.
  • 오프스크린(offscreen): 감정 분류 모델을 기기 안에서 실행하기 위해 필요합니다.
  • 활성 탭(activeTab): 확장 아이콘을 눌렀을 때 현재 사이트의 설정을 보여 주기 위해 필요합니다.

6. Chrome 웹 스토어 사용자 데이터 정책 준수

이 확장 프로그램이 받는 정보의 사용과 다른 곳으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 따릅니다.

7. 방침의 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다. 2026년 11월 13일: 고친 내용 보내기를 사용자가 동의한 뒤에만 하도록 바꾸고, 바꾼 말 보내기와 개선된 모델 받기를 더했습니다.
