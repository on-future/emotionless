# 제3자 구성 요소 고지

emotionless 는 아래 오픈소스 구성 요소를 포함합니다.

| 구성 요소 | 용도 | 라이선스 | 출처 |
|---|---|---|---|
| KOTE 감정 분류 모델 (`searle-j/kote_for_easygoing_people`) | 댓글 감정 분류. ONNX로 변환하고 8비트로 양자화해 포함 | MIT | https://huggingface.co/searle-j/kote_for_easygoing_people |
| Transformers.js (`@huggingface/transformers` 3.8.1) | 브라우저 안에서 모델 실행 | Apache-2.0 | https://github.com/huggingface/transformers.js |
| ONNX Runtime Web | 모델 실행 엔진 (WebAssembly) | MIT | https://github.com/microsoft/onnxruntime |
| Fluent Emoji (3D) | 감정 이모티콘 그림, 아이콘 | MIT | https://github.com/microsoft/fluentui-emoji |

각 라이선스 전문은 위 출처에서 확인할 수 있습니다.
