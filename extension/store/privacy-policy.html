emotionless 개인정보처리방침

시행일: 2026년 11월 12일

emotionless(이하 "확장 프로그램")는 웹 페이지의 댓글에 감정 이모티콘을 표시하고 감정 표현을 순화해 보여 주는 Chrome 확장 프로그램입니다.

1. 수집하는 정보

확장 프로그램은 어떤 개인정보도 수집하지 않습니다.

  • 개발자가 운영하는 서버가 없습니다.
  • 방문한 페이지의 주소, 댓글 내용, 사용 기록을 기기 밖으로 전송하지 않습니다.
  • 분석 도구, 광고, 추적 코드를 포함하지 않습니다.

2. 기기 안에서 처리하는 정보

확장 프로그램은 다음 정보를 사용자의 기기 안에서만 처리합니다.

  • 페이지의 댓글 글: 감정을 분류하고 순화된 글을 만들기 위해 읽습니다. 분류는 확장 프로그램에 포함된 모델이 기기 안에서 수행하며, 처리한 글은 저장하지 않습니다.
  • 설정 값: 전체 사용 여부, 사이트별 사용 여부, 댓글 접기 사용 여부, 사용자가 직접 지정한 사이트별 댓글 위치를 브라우저의 로컬 저장소(chrome.storage.local)에 저장합니다. 이 값은 기기를 떠나지 않으며, 확장 프로그램을 삭제하면 함께 삭제됩니다.

3. 제3자 제공

수집하는 정보가 없으므로 제3자에게 제공하거나 판매하는 정보도 없습니다.

4. 권한

  • 모든 사이트의 페이지 읽기 및 변경: 댓글이 있는 페이지에서 댓글을 찾아 화면 표시를 바꾸기 위해 필요합니다.
  • 저장소(storage): 위 설정 값을 기기에 저장하기 위해 필요합니다.
  • 오프스크린(offscreen): 감정 분류 모델을 기기 안에서 실행하기 위해 필요합니다.
  • 활성 탭(activeTab): 확장 아이콘을 눌렀을 때 현재 사이트의 설정을 보여 주기 위해 필요합니다.

5. 방침의 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다.
