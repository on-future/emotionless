# Chrome 웹 스토어 등록 정보

개발자 대시보드의 각 칸에 그대로 붙여 넣을 내용입니다.

## 스토어 등록정보 탭

**이름** (매니페스트에서 자동 입력)

```
Emotionless - 댓글 감정 순화
```

**요약** (매니페스트 설명에서 자동 입력, 132자 이내)

```
댓글마다 감정을 이모티콘으로 보여 주고, 욕설과 과한 감정 표현을 걷어낸 글로 바꿔 줍니다. 댓글 처리는 내 기기 안에서 이루어집니다.
```

**자세한 설명**

```
댓글로 사람들 반응은 보고 싶은데, 읽다 보면 기분이 상하시나요?

emotionless 는 댓글의 감정을 먼저 알려 주고, 날 선 표현을 걷어낸 글로 바꿔 보여 줍니다.

■ 이렇게 바뀝니다
원문: "와 결제한 지 2주 됐는데 아이템은 아직도 안 들어옴ㅋㅋㅋ 다시는 여기서 안 산다 진짜 최악"
표시: 😤 "결제한 지 2주 됐는데 아이템은 아직도 안 들어옴. 다시는 여기서 안 산다."
원문: "존나 맛있네 이 새끼들 장사 잘하네"
표시: 😀 "정말 맛있네 이 사람들 장사 잘하네"

■ 주요 기능
· 감정 이모티콘: 댓글마다 분노, 불만, 비난, 긍정, 슬픔, 불안, 놀람, 중립 중 하나를 이모티콘과 색으로 표시합니다.
· 표현 순화: 거친 말은 순한 말로 바꾸고("존나" → "정말"), ㅋㅋ·ㅠㅠ, 반복되는 느낌표 같은 군더더기는 지웁니다. 문장을 새로 지어내지 않고 그 표현만 고치므로 내용이 바뀌지 않습니다.
· 걸러 보는 정도: 감정 표시만, 표현 순화, 분노·비난 댓글 접기, 아예 숨기기 가운데 고를 수 있습니다.
· 원문 보기: 언제든 원래 글을 다시 볼 수 있습니다.
· 반응 요약: 지금까지 본 댓글의 감정 분포를 댓글 위에 막대로 보여 줍니다.
· 댓글 직접 지정: 자동으로 찾지 못한 사이트에서는 댓글 하나를 클릭해 알려 주면 그 사이트를 기억합니다.
· 판정 고치기: 감정이 틀렸으면 얼굴을 눌러 고치고, 표현은 글을 드래그해 다른 말로 바꾸거나, 지우거나, 그대로 두라고 알려 줄 수 있습니다. 고친 내용은 바로 반영됩니다.

■ 내 기기 안에서 처리합니다
· 감정 분류 모델이 확장 프로그램 안에 들어 있어, 댓글을 읽고 바꾸는 일은 모두 내 기기 안에서 이루어집니다.
· 계정과 로그인이 필요 없습니다.
· 화면에 보이는 댓글만 처리해 빠르고 가볍습니다.
· 처음 판정을 고칠 때 고친 내용을 개선에 보낼지 여쭙니다. "보내기"를 고른 경우에만 그 댓글의 글과 고친 내용을 서버로 보내 모델을 다시 학습하는 데 씁니다. 고치지 않은 댓글은 보내지 않고, 설정에서 언제든 바꿀 수 있습니다.
· 모델 업데이트: 하루 한 번 개선된 판정 모델이 있는지 확인해 받습니다. 받는 것은 개발자가 서명한 모델 파일(가중치와 계산 구조)뿐이며, 실행 코드는 받지 않습니다.

■ 알아 두실 점
· 한국어 댓글을 대상으로 합니다. 다른 언어의 댓글은 그대로 둡니다.
· 감정 판정은 자동 분류라 틀릴 수 있습니다. 비꼬는 말을 긍정으로 보는 경우가 있습니다.
· 사이트 구조에 따라 댓글을 찾지 못할 수 있습니다. 이때는 "댓글 직접 지정"을 써 주세요.
· 모델이 포함되어 설치 용량이 약 30MB 입니다.

■ 설정
확장 아이콘을 눌러 전체 켜기/끄기, 사이트별 켜기/끄기, 접기 사용 여부를 바꿀 수 있습니다.

■ 오픈소스 고지
KcELECTRA-small(MIT), KOTE 데이터셋(MIT), K/DA 데이터셋(Apache-2.0), KOTOX 데이터셋(MIT), ONNX Runtime Web(MIT), Fluent Emoji(MIT)를 사용합니다.
```

## 개인 정보 보호 탭

**단일 목적 설명**

```
웹 페이지의 한국어 댓글에 감정 이모티콘을 붙이고, 거친 말은 순한 말로 바꾸고 과한 감정 표현은 걷어낸 글로 보여 주는 것이 유일한 목적입니다.
```

**권한 사용 이유**

storage

```
사용자가 고른 설정(전체 켜기/끄기, 사이트별 켜기/끄기, 접기 사용 여부, 사이트별로 직접 지정한 댓글 위치)을 기기 안에 저장하는 데 씁니다.
```

offscreen

```
확장 프로그램에 포함된 감정 분류 모델(WebAssembly)을 실행하려면 DOM 환경과 워커가 필요합니다. 서비스 워커에서는 실행할 수 없어 오프스크린 문서에서 모델을 돌립니다. 이 문서는 외부와 통신하지 않습니다.
```

activeTab

```
사용자가 확장 아이콘을 눌렀을 때, 현재 탭의 주소에서 사이트 이름을 읽어 "이 사이트에서 사용" 설정을 보여 주고, 설정을 바꾸면 그 탭을 새로 고치는 데 씁니다.
```

호스트 권한 (콘텐츠 스크립트가 모든 http/https 페이지에서 실행됨)

```
댓글은 뉴스, 커뮤니티, 쇼핑몰 등 어느 사이트에나 있을 수 있어 특정 사이트 목록으로 제한할 수 없습니다. 콘텐츠 스크립트는 페이지에서 댓글 영역을 찾아 그 글을 기기 안의 모델로 분류하고, 이모티콘과 순화된 글을 화면에 표시하는 일만 합니다. 페이지 내용은 기기 밖으로 전송되지 않습니다.
```

**원격 코드 사용 여부**: 아니요, 원격 코드를 사용하지 않습니다.

(스크립트와 WebAssembly 실행 파일은 모두 패키지 안에 들어 있습니다. 개선된 모델 파일(ONNX: 가중치와 계산 구조)을 서버에서 받을 수 있지만, 이는 실행 코드가 아니라 패키지 안의 실행기가 읽는 데이터이며, 개발자 서명을 확인한 것만 씁니다. 아래 "테스트 안내"에 같은 내용을 적어 심사자에게 알립니다.)

**데이터 사용**

- 수집하는 사용자 데이터 항목: "웹사이트 콘텐츠"를 선택합니다. 사용자가 동의한 뒤 판정을 고치면 그 댓글의 글이 서버로 전송되기 때문입니다.
- 아래 세 가지 확인란은 모두 선택합니다.
  - 승인된 사용 사례 외에 사용자 데이터를 제3자에게 판매하거나 전송하지 않습니다.
  - 항목의 단일 목적과 관련 없는 용도로 사용자 데이터를 사용하거나 전송하지 않습니다.
  - 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않습니다.

**개인정보처리방침 URL**: https://on-future.github.io/emotionless/privacy.html

## 테스트 안내 탭

**테스트 안내** (심사자에게 보이는 칸)

```
[테스트 방법]
1. 확장 프로그램을 설치하고 한국어 댓글이 있는 페이지를 엽니다. 예: https://news.nate.com 의 기사 댓글, https://www.youtube.com 의 한국어 영상 댓글.
2. 댓글마다 감정 이모티콘이 붙고, 거친 표현은 순한 말로 바뀌거나 지워진 글이 보입니다. 말풍선을 누르면 원문을 볼 수 있습니다.
3. 얼굴을 누르면 감정을 고칠 수 있고, 글을 드래그하면 "바꾸기 / 지우기"를 고를 수 있습니다.
4. 처음 고칠 때 "고친 내용을 보내 개선에 쓸까요?" 안내가 뜹니다. "보내기"를 고른 경우에만 그 댓글의 글과 고친 내용을 보냅니다. "보내지 않기"를 고르거나 닫으면 보내지 않습니다.
로그인이나 계정은 필요 없습니다.

[모델 업데이트에 대해 미리 알려 드립니다]
이 확장 프로그램은 하루 한 번 https://emotionless-api.didd.kr/v1/model/manifest.json 을 확인해, 사용자 교정으로 다시 학습한 판정 모델 파일(ONNX)이 있으면 받아서 씁니다.
- 받는 것은 모델의 가중치와 계산 구조뿐이며, JavaScript나 WebAssembly 같은 실행 코드는 받지 않습니다. 모델은 패키지에 포함된 onnxruntime-web 으로만 실행합니다.
- 모델 설명은 개발자의 Ed25519 키로 서명되어 있고, 패키지에 든 공개 키로 서명과 SHA-256 해시, 크기, 감정 라벨 순서, 단어장 해시를 확인한 뒤에만 씁니다. 하나라도 맞지 않으면 버리고 패키지에 든 기본 모델을 씁니다.
- 관련 코드: background.js 의 syncModel, offscreen.js 의 load, shared/model-store.js.
- 이 확인 요청에는 사용자 정보가 담기지 않습니다.
```
